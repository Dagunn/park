## Запуск

```bash (терминале) ввести команды:
npm install
npm run dev
npm run build   # production-сборка в dist/
```

Готовая вёрстка собирается в `dist/`. Папка в `.gitignore`, в репозитории её нет — после клонирования выполните `npm run build`.

Скорость (Lighthouse) мерить на собранном `dist` на сервере со сжатием (gzip/brotli) или на стенде. Dev-сервер отдаёт файлы без сжатия, цифры там занижены.

## Структура

```
src/
  index.html                 страница: head, шапка, секции, подвал
  partials/
    head.html                meta, стили, скрипты
    header.html              шапка
    footer.html              подвал
    sections/                секции главной (hero, spotlight, hobbies, events, map, news, journal, about, partners)
    components/
      park-options.html      список парков для выпадающих списков (Афиша, карта)
  styles/
    main.css                 точка входа Tailwind
    base/                    токены (theme.css, responsive.css), шрифты, базовые стили
    components/              компоненты: кнопки, карточки, формы, шапка, подвал, карта, select2 и т. д.
    utilities/               свои утилиты Tailwind
  js/
    main.js                  весь JS страницы
  assets/
    fonts/                   PT Root UI (400, 500), woff2
    icons/                   SVG-иконки, вставляются в разметку через @@include
    images/                  исходники картинок
gulpfile.js                  сборка
```

Части страницы собираются через `@@include` (gulp-file-include). Шапка и подвал — отдельные файлы, вне `<main>`.

## JS

Весь код в `src/js/main.js`, без сборщика. JS находит элементы только по `data-`атрибутам. Классы отвечают только за оформление, их можно менять.

## select2 и jQuery

Выпадающие списки «Все парки Москвы» (Афиша и карта) — `<select>` + select2 4.1.0 с поиском и русской локализацией. select2 требует jQuery, подключена 3.7.1. Обе библиотеки ставятся из npm и при сборке копируются в `dist/js/vendor/`.

- Тема оформления — `theme: 'park'`, стили в `src/styles/components/select.css`. Поле select2 получает классы исходного `<select>` (`.select` или `.select-line`), поэтому без JS список выглядит так же.
- События select2 слушаются **через jQuery**, обычный `addEventListener('change')` при выборе через select2 не сработает.

## Уточнения

- **Хлебные крошки.** На главной их нет. На внутренних страницах ставить между `</header>` и `<main>`, не внутри контента — место отмечено комментарием в `src/index.html`.
- **Второй слайд hero** (`src/partials/sections/hero.html`) — заглушка: фото и текст. В макете нарисован только первый.
- **Список парков** (`src/partials/components/park-options.html`) — заглушка. `value` у `<option>` — идентификатор парка.
- **Карта** (`src/partials/sections/map.html`) — статичная картинка из макета.Округа и интересы у отметок (`data-district`, `data-interests`) — условные.
- **Ссылки** ведут на `#`
